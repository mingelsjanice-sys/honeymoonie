# Honeymoon Atlas v5

Personal Italy honeymoon roadtrip planner.

## Render
- Build: `npm install`
- Start: `npm start`
- Environment variable: `APISH_KEY`

## Live accommodation data
Uses API.SH's current Skyscanner hotel endpoint for date-specific prices, photos and booking-site offers. The server keeps the API key private.

## Route
Uses OSRM for road distance and driving time.

## Map
Leaflet + OpenStreetMap tiles.
